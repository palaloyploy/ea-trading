## 1. สรุปสั้นที่สุด

* **ระบบที่ได้กำไรจริง** คือ "แท่งคู่ H1 + แท่งกลืนไส้บน M15" กรองด้วย **EMA200 (H1)**, **ADX ≥ 20** และ **RSI Range Rule 40/60**
* ทดสอบใน MT5 กับ tick จริงของโบรก (ม.ค.–พ.ย. 2026, ทุน $100, 0.01 lot): **+$31, ชนะ 62.5%, Profit Factor 1.63, ติดลบหนักสุด 16%** แต่เข้าน้อย (16 ไม้ ใน 10 เดือน)
* **ท่าเข้าถี่ทั้งหมด** (ทริค M1, ไส้กระสือ, Flip, Gap, VBC) **ขาดทุน** เมื่อให้ EA เข้าทุกครั้งที่เข้าเงื่อนไข
* เหตุผลหลัก: โค้ชได้เงินเพราะ **เลือกไม่เข้าไม้ที่ไม่สวย** ส่วนนี้ยังเขียนเป็นกฎไม่ได้ และในคลิป/รูปเราเห็นแต่ไม้ชนะ
* ทองปี 2026 ผันผวนกว่าปี 2023 ประมาณ **4 เท่า** (ATR H1 ~1,840 จุด เทียบกับ ~450 จุด) ท่าที่ใช้ SL แคบจึงพังง่าย

หน่วย: **1 จุด = $0.01** · 0.01 lot = กำไร/ขาดทุน $1 ต่อราคาขยับ $1

## 2. เทคนิคของโค้ช

ที่มา: E-Book "เทรดท่าเดียว ฉบับสมบูรณ์", คลิปในกลุ่ม Facebook "E-Book โค้ชน้ำเทรดท่าเดียว", แชท LINE กลุ่ม

### 2.1 แท่งคู่ (แนวรับ-แนวต้าน)
* **แนวรับ:** แท่งแดงตามด้วยแท่งเขียว ที่จุดต่ำ → โซน = ไส้ล่างของคู่ (จากหัวแท่งต่ำสุดถึงปลายไส้)
* **แนวต้าน:** แท่งเขียวตามด้วยแท่งแดง ที่จุดสูง → โซน = ไส้บนของคู่
* ตีบน H1 เป็นหลัก (โค้ชใช้ H4, M30 ประกอบ)
* ใช้โซนเดิมไม่เกิน 2 ครั้ง (E-Book)
* จากคลิป: โซนของโค้ชบางมาก (~$6–8) และลากยาวข้ามหลายวัน มักเป็นยอด/ก้นสวิงที่ราคาเคยเด้งหลายรอบ

### 2.2 การเข้าไม้ (Wick-Fill)
* ราคาวิ่งออกจากโซน แล้วกลับมาแตะ
* ย่อลง TF เล็ก (M15/M5/M1) รอ **แท่งกลืนไส้ (cf PA)** = แท่งที่ปิดเหนือ High แท่งก่อนหน้า (Buy) / ต่ำกว่า Low (Sell)
* เข้า **Limit ที่ปลายไส้แท่งก่อนหน้า**
* ไล่เทรน: แท่งเขียวกลืนไส้แท่งเขียวก่อนหน้า → Buy เพิ่มที่ไส้แท่งก่อนหน้า SL ใต้แท่งปัจจุบัน
* ระวังโซนตรงข้าม ("กรอบเขียว") ที่ TP ต้องวิ่งผ่าน

### 2.3 ลำดับเข้าแบบคม (EP.1.1, เขียนบนจอ)
> ชนแนวรับ-ต้านแท่งคู่ → ถอดไส้กระสือ → แท่งกลืนกิน cf PA → Gap

* **ไส้กระสือ** = แท่งที่ทิ้งไส้ยาวแทงเข้า/ทะลุโซนแล้วปิดกลับ
* ตัวอย่างในคลิป: M1, 5/9/11 มิ.ย. 2026 (เช่น Sell 4,097 SL 4,107 TP 4,090 วันที่ 11 มิ.ย. 12:53)

### 2.4 ท่าจิ้มจุ่ม: เข้าด้วย Gap (EP พิเศษ, เขียนบนจอ)
* **ก่อนเข้า:** 1) ดูเทรน 2) **ดูแท่งเทียน Day / H4** 3) ดูโครงสร้าง
* **ขั้นตอน:** 1) ตีไส้บน-ไส้ล่าง หรือแท่งที่ราคายังไม่ได้ใช้ (Gap) 2) ย่อลง M5 3) รอ M5 cf

### 2.5 ทริคเล็ก (แชท LINE 6 พ.ย. 2026)
> "ถึงโซนใหญ่ๆ RSI แตะ OVS + M1 ถอดไส้ กดเลย" · "รวบรอบละ 500–600 จุด" · "800–900 จุดปิดละ" · "อย่าย้ำเยอะ เผื่อรอเติมตอนย่อ" · "รอจังหวะชัดๆ setup สวยๆ (volume สนับสนุน)"

### 2.6 ศัพท์อื่นที่เจอ
| คำ | ความหมายที่เข้าใจ |
|---|---|
| cf | แท่งยืนยัน = แท่งกลืนไส้แท่งก่อนหน้า |
| Flip | แนวรับโดนทะลุ → กลายเป็นแนวต้าน (และกลับกัน) |
| Gap | Fair Value Gap 3 แท่ง หรือช่วงไส้ที่ราคายังไม่เคยเทรดผ่าน |
| ขา 2 | เด้งกลับมาแตะรอบที่ 2 |
| VBC | **ยังไม่แน่ชัด** น่าจะเป็นแท่งใหญ่ที่ volume หนุน |
| HDB | **ยังไม่รู้ความหมาย** ("M30 เนื้อปิดเหนือแท่งก่อนหน้า ยังลงไม่ได้ เพราะทำ HDB ขวาง") |
| RSI 40/50/60 | RSI Range Rule (Cardwell): ขาขึ้น RSI ไม่หลุด 40, ขาลง RSI ไม่เกิน 60 |

### 2.7 กฎ E-Book อื่นๆ
* ไม่เทรดสวนเทรน, ไม่เทรดตอน Sideway, เลี่ยงข่าวกล่องแดง
* แนะนำช่วงยุโรป-อเมริกา (13:00–23:00 เวลาไทย) — ทดสอบแล้ว **ไม่ช่วย**
* ทุน $100 ใช้ 0.01 lot, SL ~500 จุด, TP ~300 จุด, เลื่อน SL บังหน้าทุนที่ 200 จุด

## 3. EA ทำงานยังไง

ไฟล์: `WickFill_H1Pair_EA.mq5` (MT5, ต้องใช้บัญชี **Hedging**)

### 3.1 โมดูล
| โมดูล | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| ระบบหลัก | **เปิด** | โซนแท่งคู่ H1 → กลืนไส้ M15 → Limit ปลายไส้ / FVG |
| ไล่เทรน | เปิด (1 ไม้) | แท่งใหญ่ ≥300 จุด กลืนไส้แท่งสีเดียวกัน → เข้าเพิ่ม |
| เล่นต่อหลังโซนทะลุ | ปิด | โซน H1 โดนปิดทะลุ → รอเล่นกลับที่ยอด/ก้น M15 |
| ทริค M1 | ปิด | โซนใหญ่ + RSI M1 ≤ 20 + M1 ถอดไส้ (+ เติมตอน cf) |

### 3.2 ตัวกรอง
| ตัวกรอง | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| EMA200 บน H1 (ตามเทรน) | เปิด | สำคัญที่สุด ปิดแล้วขาดทุนหนัก |
| RSI Range 40/60 (RSI9 H1, 10 แท่ง) | เปิด | ชนะสูงขึ้น เสี่ยงน้อยลง แต่ตัดไม้ ~80% |
| ADX H1 ≥ 20 | เปิด | กรอง Sideway |
| แท่ง D1 ล่าสุดสีเดียวกับทิศ | ปิด | จากคลิปท่าจิ้มจุ่ม (v2.4) |
| RSI14 M15 ยังไม่ฟื้นตอนเข้า | ปิด (0) | จากการเรียนรู้ ตั้ง 4 = เข้าเมื่อ RSI ≤ 46 (Buy) |
| ข่าว USD กล่องแดง ±30 นาที | เปิด | ใช้ได้เฉพาะตอนรันจริง |
| สเปรด ≤ 50 จุด, ≤ 2 ไม้พร้อมกัน, ≤ 4 ไม้/วัน | เปิด | |
| เช็ก Trade mode ของสัญลักษณ์ | เปิด | เตือนถ้าสัญลักษณ์ "Close only" |

### 3.3 SL / TP
* SL 1,000 จุด, TP 1,000 จุด
* TP ชนเลขกลม $20 → เลื่อนมาก่อนถึง $1 (ช่วยได้จริง)
* TP ชนโซนตรงข้าม → เลื่อนมาก่อนถึงโซน, ห่างโซน < 500 จุด ไม่เข้า
* **ไม่**เลื่อน SL บังหน้าทุน (ทดสอบแล้วแย่ลง)

## 8. บทเรียนสำคัญ

1. **ภาพเดียวกันเกิดบ่อยมาก บางครั้งได้ บางครั้งเสีย** โค้ชได้เงินเพราะเลือกไม่เข้าไม้ที่ไม่สวย EA เข้าทุกครั้ง
2. **รูปและคลิปมีแต่ไม้ชนะ** กฎที่เขียนจากไม้ชนะจะเข้าไม้แพ้ไปด้วยเสมอ ต้องได้ตัวอย่าง "ไม้ที่ไม่เข้า" ถึงจะพัฒนาต่อได้
3. **ปรับค่าบนข้อมูลชุดเดียวแล้วสวย ≠ ใช้ได้จริง** ต้องแยกช่วงเรียน/ตรวจ/ทดสอบ และยืนยันใน MT5 ทุกครั้ง
4. **ตามเทรน EMA200 สำคัญที่สุด** ปิดแล้วขาดทุนหนักทุกการทดสอบ
5. **% ชนะสูง ≠ ได้เงิน** ตั้ง TP เล็กกว่า SL ทำให้ชนะ 65–80% ได้ แต่เงินไม่เพิ่ม
6. **ความผันผวนเปลี่ยนตลอด** ทองปี 2026 แกว่งกว่าปี 2023 ~4 เท่า SL คงที่เดิมเล็กลงเมื่อเทียบ
7. **ระวังตัวทดสอบโกงตัวเอง**: เคยนับ TP ในแท่งเดียวกับที่ Limit แมตช์ ทำให้ผลดูดีเกินจริงหลายร้อย $

## 12. สิ่งที่ยังค้าง / ขั้นต่อไป
